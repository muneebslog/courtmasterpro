# Dark Mode Design Document (Minimal)
## BTMS — Public Pages Only

---

## 1. Scope (Very Important)

This design document applies **ONLY** to:

- Public tournament listing
- Public match listing
- Public match score page

Nothing else.

No landing pages  
No marketing sections  
No feature highlights  
No pricing  
No dashboards  

Public flow is strictly:

Tournament → Matches → Score

---

## 2. Design Philosophy

- Zero clutter
- Zero decoration
- Zero distractions
- Maximum readability

This UI is:
- Functional
- Fast
- Calm
- Trustworthy

If an element does not help the user:
**find a match or read a score → it must not exist.**

---

## 3. Color System (Dark Only)

### Backgrounds
- Primary Background: `#0B0F14`
- Secondary Background: `#0F1621`
- Row Hover Background: `#111827`

### Text
- Primary Text: `#F9FAFB`
- Secondary Text: `#D1D5DB`
- Muted Text: `#9CA3AF`

### Status Colors (Strict)
- Live: `#22C55E`
- Scheduled: `#6B7280`
- Completed: `#3B82F6`
- Bye / Cancelled: `#EF4444`

No gradients  
No glow  
No neon  
No decoration colors

---

## 4. Typography

### Font
- Inter
- system-ui fallback

### Sizes
- Page Title: 22–24px
- List Item Title: 16–18px
- Body Text: 14–15px
- Meta Text: 12–13px

### Rules
- No oversized headings
- No dramatic hero text
- Text must be readable from distance
- Numbers (scores) must stand out

---

## 5. Layout Rules

- Single-column layout
- Centered container
- Max width: 900–1000px
- Generous vertical spacing
- No sidebars
- No cards unless necessary
